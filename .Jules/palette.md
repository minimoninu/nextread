## $(date +%Y-%m-%d) - Adding consistent aria-label to icon-only header buttons
**Learning:** Icon-only buttons often rely only on the `title` attribute, which functions as a tooltip for mouse users but does not always consistently map to screen reader announcements compared to an explicit `aria-label`. We found icon buttons in `src/App.jsx` under the app header (Sanctuary, Theme, Stats, Authors, Filters, Volver al inicio) that were either missing `title` entirely, missing `aria-label`, or both.
**Action:** Consistently bind `title` (for visual tooltip) and `aria-label` (for screen readers) together on all icon-only buttons using localized strings (like `COPY.sanctuary.enter`). Added `aria-label`s to Sanctuary button, Theme toggle, Modo Hoy toggle, Stats, Authors, Filters, and "Volver al inicio" button in `src/App.jsx`.

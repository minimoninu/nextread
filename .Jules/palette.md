## 2026-03-04 - Empty State Polish\n**Learning:** When adding purely decorative emojis to empty states to improve visual feedback, they must explicitly be hidden from screen readers using `aria-hidden="true"` to prevent confusing literal character readouts (e.g., 'left-pointing magnifying glass').\n**Action:** Always wrap decorative emojis or icons in containers with `aria-hidden="true"` or use `role="img"` with a descriptive `aria-label` if they convey semantic meaning.
